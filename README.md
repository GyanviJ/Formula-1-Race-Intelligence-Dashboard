# 🏎️ Formula 1 Race Intelligence Dashboard

An interactive data visualisation project that explores Formula 1 racing performance, driver statistics, team comparisons, circuit locations, and race outcomes using Tableau.

## 📌 Project Overview

The Formula 1 Race Intelligence Dashboard transforms racing data into interactive visual insights. It helps users explore driver performance, compare teams, analyse Did Not Finish (DNF) patterns, and understand trends across racing seasons.

The project also includes a supporting website built with Flask, HTML, and CSS to present the dashboard and project information.

## 🎯 Objectives

- Analyse driver performance and cumulative points.
- Compare team performance across seasons.
- Examine DNF reasons and driver reliability.
- Explore circuit locations and geographic participation.
- Present key statistics through KPI cards and interactive charts.
- Make project findings accessible through a dedicated website.

## ✨ Key Features

- **KPI Cards:** Summary statistics for teams, seasons, race outcomes, and circuits.
- **Driver Leaderboard:** Compare drivers using points and rankings.
- **Reliability Analysis:** Explore DNF counts and retirement reasons.
- **Team Analysis:** Compare team championship performance.
- **Geographic Visualisation:** Explore circuit locations and participation.
- **Interactive Filters:** Investigate data by season, DNF reason, and selected Top N values.
- **Tableau Story:** Present the project's analysis in a structured narrative.
- **Project Website:** A Flask-based interface for presenting the project.

## 🚀 Running the Website Locally

### Prerequisites

- Python installed on your computer.
- The project website files, including `app.py`, the `templates` folder, and the `static` folder.

### Installation

1. Clone or download this repository.
2. Open a terminal in the website project directory.
3. Install Flask:

   ```bash
   python -m pip install flask
   ```

4. Start the website:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000/` in your browser.

The Tableau views require an internet connection and must be publicly accessible for embedding to work.
